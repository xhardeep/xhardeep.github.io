# Welcome to my new blog

This blog is built using **Astro** and the **Spearhead** theme aesthetics.

## Why Astro?
Astro is a modern web framework that prioritizes content and performance. It allows me to write posts in Markdown while maintaining a high-quality design.

### Markdown Support
You can use standard Markdown features like:
- Lists
- **Bold text**
- *Italic text*
- [Links](https://astro.build)

Enjoy!
